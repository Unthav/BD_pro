# Portfolio Website

Plain HTML5, CSS3 and JavaScript. No build step needed.

## Customize
1. Open `index.html` and replace every `[Placeholder]` with your details.
2. Add your resume as `resume.pdf` in the same folder as `index.html`.
3. Change colors in `css/style.css` (variables at the top, `--accent` is the main color).

## Deploy on GitHub Pages
1. Create a new repository on GitHub (for a personal site, name it `yourusername.github.io`).
2. Upload all files from this folder (keep `css/` and `js/` folders as they are).
3. Go to Settings > Pages > Source: "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://yourusername.github.io`.
